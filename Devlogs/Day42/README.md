# 42일차 — 협동 보안·안정성

## 이번 일차 목표

협동은 **방장이 심판**인 구조다. 41일차까지는 심판이 참가자의 요청을 거의 그대로 믿었다. 42일차에는 방장이 요청을 **확인하고, 너무 잦으면 무시하고, 계속되면 내보내게** 만든다. 방장에게는 관리 버튼도 준다.

```text
참가자 요청 → [횟수 한도] → [값 검사: NaN·좌표·길이] → [거리·소지·열쇠·무기 확인] → 적용·방송
                      └ 어기면 경고 누적 (초당 1씩 감소) → 40 초과 시 자동 내보내기
```

## 1. 방장 전용 방송 권한

- Netcode 2.13의 `[Rpc]`는 기본 `InvokePermission = Everyone`이다. 그래서 **참가자도 `SendTo.NotServer` 방송을 보내면 방장이 다른 대원에게 전달**해 준다. 조작한 게임으로 가짜 피해·아이템 이동·문 열기를 퍼뜨릴 수 있었다.
- 방장만 보내는 알림 18개를 `InvokePermission = RpcInvokePermission.Server`로 바꿨다.
  - `NetItemSync`: 아이템 변경·생성·되돌리기·알림·목록 조각
  - `NetCombatSync`: 몬스터 상태·휘두르기·화살·대원 피해·체력·함정·장치·전체 상태·장치 되돌리기
  - `NetWorldState`: 종·알림·전체 알림·문 상태

## 4. 연결

### Steam (`SteamNetworkTransport`)
- 연결을 받기 전에 `Admission`으로 판정한다: 차단 → 잠금(처음 오는 대원) → **현재 로비 멤버인지**.
  - 로비 입장 반영이 늦을 수 있어 최대 6초 기다린다.
- 연결별 상대 Steam ID를 기록한다(`TryGetPeer`).
- 초당 3000개가 넘는 메시지나 512KB가 넘는 메시지를 보내는 연결은 끊는다.
- 내보낼 때는 남은 신뢰 메시지(이유)를 보낸 뒤 닫는다(`linger`).
- 지연 조회를 넷코드 대원 번호 → 연결 번호로 바꿨다.

### 접속 확인 (`NetworkSession.ApproveConnection`)
- 접속 데이터가 256바이트를 넘으면 거절한다. 데이터 형식은 `버전[\n암호]`다.
- 대원 식별 키는 `steam:ID` 또는 `ip:주소`다(Netcode `GetEndpoint`).
- 확인 순서: 차단 → 잠금 → Steam 로비 멤버 → 직접 IP 방 암호 → 인원

### 방장 관리
- `Kick(대원, 차단)`: 이유를 보낸 뒤 끊고, 모두에게 알린다. 차단 목록은 새 방을 열면 초기화된다.
- `SetRoomLocked`: 새 입장을 막는다. 이미 들어왔던 대원의 재접속은 허용하고, Steam 로비는 참가 불가로 바꾼다.
- 방 닫기: 참가자마다 `방장이 방을 닫았습니다`를 보낸 뒤 두 프레임 뒤에 종료한다.

### 참가자 재접속 판단
- 넷코드는 일반 끊김에도 `[Disconnect Event]…` 문구를 채운다 → `ServerReason()`으로 **방장이 보낸 이유만** 골라낸다.
- 방장이 이유를 보냈거나(닫기·내보내기·차단·잠금·암호·버전) **Steam 로비 주인이 바뀌었으면**(`방장이 방을 떠났습니다`) 재접속하지 않는다.

## 5. 화면

- **서버 창**: 오른쪽에 `암호` 칸을 추가했다(가림 표시, 32자). 주소 방을 만들 때와 입장할 때 함께 쓴다.
- **Esc 창**: `원정대원` 버튼을 추가했다. 협동 중에만 보이며, 원정대원·친구 초대·코드 복사 중 보이는 버튼만 위에서부터 배치한다. 코드 줄에 `암호 사용 · 잠김`도 표시한다.
- **원정대원 창 `CrewPanel`**
  - 이름·[방장]·(나)·지연을 보여 준다. 지연은 1초마다 제자리 갱신하고, 목록이 바뀔 때만 다시 그린다.
  - 방장은 `[ 내보내기 ] [ 차단 ]`을 **두 번 눌러야** 실행된다(3초 안).
  - `방 잠그기 [ ]` 토글이 있다.
- **이름표**: 받은 이름도 방장·대원 화면에서 다시 정리한다. 받은 위치·방향이 비정상이면 마지막 위치를 유지한다.

## 한계·남은 것

- 방장 본인의 조작은 막을 수 없다(방장 = 서버).
- 참가자가 자기 몸 위치를 조작하는 것(순간이동)은 아직 검사하지 않는다 → 거리 검사를 우회할 수 있다.
- 직접 IP 방 암호는 암호화 없이 전송된다(같은 네트워크·개발용).
- 같은 PC에서는 두 게임의 IP가 같아서, 차단하면 그 방에는 이 PC에서 더 들어갈 수 없다.
- 이모지는 이름에서 제거된다.
