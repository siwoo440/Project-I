## 개발 목표

Day27의 지하 실내 던전은 **한 층짜리 평면**이었다.

Day28에서는 메인 방이 있는 층을 1층으로 보고 **위·아래로 층을 늘렸다.**
층과 층은 문으로 바로 잇지 않고 **세로형 방**으로만 연결한다.

확정한 규칙:

```text
메인 방이 있는 층 = 1층 / 위로 2F·3F / 아래로 B1·B2
층 이동은 세로형 방으로만 한다 (계단통 · 사다리 방 · 수직 통로)
세로형 방은 아래층과 위층 격자를 동시에 차지한다 (다른 방이 못 쓴다)
위층이 생겨도 지형을 절대 뚫지 않는다 (최상층 천장 기준으로 깊이를 잡는다)
서브문은 외부와 이어지는 1층에만 둔다
계단은 앞으로 가는 키만으로 걸림 없이 오른다
사다리는 F로 타고 W·S로 오르내린다
```

# 1. 격자에 층 좌표 추가

`GridPoint`에 `Floor`를 넣어 같은 칸이라도 층이 다르면 다른 칸이 되게 했다.

```text
GridPoint(X, Y, Floor)
  Floor 0  = 1층 (메인 방)
  Floor +N = 위층   → "2F", "3F"
  Floor -N = 지하층 → "B1", "B2"

Step(방향)   같은 층에서 한 칸 이동
Above/Below  한 층 위·아래 같은 칸
```

문(`DoorEdge`)에도 `Floor`를 넣었다.
세로형 방은 아래층과 위층에 각각 문을 하나씩 가지므로
문이 어느 층에 놓였는지를 알아야 벽 구멍과 통로 높이를 정할 수 있다.

# 2. 세로형 방 — `RoomKind.Vertical`

```text
Stairwell  계단통    — 걸어서 오르내림
Ladder     사다리 방  — F로 타고 W/S
Shaft      수직 통로  — 사다리와 같은 방식, 복도 크기(3.5m)
```

한 세로형 방은 **아래층 칸과 위층 칸 2개를 점유**한다.

```text
방 데이터
  Cell       아래층 칸
  LowerWall  아래층 문이 있는 벽
  UpperWall  위층 문이 있는 벽 (LowerWall과 달라야 함)
  ClimbWall  계단이 시작하는 벽 / 사다리가 붙는 벽
```

`LowerWall ≠ UpperWall` 규칙은 계단 구멍·사다리 구멍 위로 문이 열려
곧바로 아래로 떨어지는 배치를 막기 위한 것이다.

사다리는 문이 없는 벽에만 붙이고, 계단은 아래층 문 벽에서 시작해
반대쪽으로 올라간다.

# 3. 생성 순서

```text
1. 1층 생성 (Day27과 동일: 시작 방 → 주 경로 → 분기)
2. 위로 한 층씩 → 아래로 한 층씩 순서로 확장
   a. 기존 층 방 옆의 빈 칸을 찾는다
      (그 칸이 새 층에서도 비어 있어야 한다)
   b. 세로형 방을 놓고 기존 층 문을 연결한다
   c. 새 층 출구 벽을 고른다 (기존 층 문과 같은 벽 금지)
   d. 새 층 첫 방을 만들고 연결한 뒤 그 층을 목표 방 수까지 키운다
3. 층마다 순환로 추가 · 막다른 방 보정
4. 직선 통과 방을 복도로 지정 (묶음 최대 3개, 전체 1/4 이하)
5. 잠긴 문·열쇠 (세로형 방 문은 제외 → 층 전체가 잠기지 않게)
6. 서브문 (1층만, 외부 서브문 수와 동일)
7. 회수품·함정·몬스터 후보 (세로형 방 제외)
```

방 수 규칙:

```text
1층      14 ~ 20
그 외 층   6 ~ 11
```

# 4. 지형 관통 방지 — 위층이 생겨도 유효

Day27은 1층 천장 기준으로 깊이를 잡았다.
위층이 생기면 그 기준으로는 지형을 뚫는다.

```text
최상층 천장 = 외부 씬 최저 높이 − 여유 깊이(12m)
1층 바닥    = 최상층 천장 − (위층 수 × 층 높이) − 방 높이 − 벽 두께
층 높이      = 방 높이 4m + 벽 두께 0.4m × 2 = 4.8m
```

테스트 던전 결과:

| 층 | 바닥 높이 |
|---|---|
| 3F | -21.4 |
| 2F | -26.2 |
| 1F | -31.0 |
| B1 | -35.8 |
| B2 | -40.6 |

```text
외부 최저 -5.0 → 한계 -17.0
생성물 최고 -17.0 (최상층 천장)
각 방 위 지형 표면까지 최소 16.3m
```

# 5. 계단통 — 앞으로 가는 키만으로 오른다

```text
계단 시작  아래층 문 벽에서 0.9m 안쪽 (진입 평지)
계단 끝    반대쪽 벽
수평 6.1m · 높이 4.8m → 기울기 38.2°
디딤판 16칸 (한 칸 0.3m)
계단 폭 2.6m — 방 폭 7m 중 한쪽에 붙임
```

```text
보이는 디딤판 : 충돌체 없음
실제 바닥     : 보이지 않는 경사 상자 충돌체 1개
```

디딤판마다 충돌체를 두면 `CharacterController`의 Step Offset(0.3m)에 걸려
끊기거나 튀는 느낌이 난다.
그래서 **계단 모양은 눈으로만 보이고, 실제로 밟는 것은 경사면 하나**다.
`Slope Limit`이 50°이므로 38.2° 계단은 걷기만으로 부드럽게 올라간다.

```text
위층 바닥 : 계단 옆 나머지 폭(4.4m)에 깔고
난간      : 계단 쪽 모서리에 0.6m 높이로 세워 실수로 떨어지는 것을 막음
계단 측면 : 위층 문이 있는 벽을 피해서 고름
```

# 6. 사다리 방·수직 통로 — F로 타고 W/S

```text
위층 바닥에 사다리 앞 구멍만 비움 (1.6m × 1.3m)
사다리는 벽에 붙여 세우고 위층 바닥보다 1m 더 올라옴
  → 위층에서도 사다리를 보고 F를 누를 수 있다
```

`PlayerMovement`에 사다리 상태를 추가했다.

```text
F  →  BeginClimb
      중력·수평 이동을 끄고 사다리 중심선으로 몸을 붙인다
      플레이어를 사다리 쪽으로 돌린다

W  →  위로, S → 아래로 (2.4m/s)

끝에 도달하거나 F·Space → 내림
      위 끝이면 위층 바닥, 아래 끝이면 아래층 바닥으로 내려선다
      내린 직후 추락 판정 기준을 새 위치로 초기화 (피해 없음)
```

순간이동·마차 이동이 일어나면 사다리 상태는 자동으로 해제된다.

위층이 생겨도 최상층 천장을 기준으로 깊이를 다시 계산해
