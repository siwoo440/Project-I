# 32일차 — 판매대 올려두기 · 판매 벨 선택 판매

## 이번 일차 목표

판매대에 회수품을 대면 **바로 팔리던** 방식을, **올려두고 → 벨을 눌러 → 팔 물건을 고르는** 방식으로 바꾼다. 실수로 파는 일을 막고, 무엇을 팔지 한 번에 비교해 고를 수 있게 한다.

```text
이전  회수품 들고 판매대에 F → 즉시 판매
이후  회수품 들고 판매대에 F → 판매대 위에 놓임 (F로 다시 집을 수 있음)
      벨에 F → 판매 선택 창 → 팔 물건 체크 → [판매]
      → 고른 물건만 줄어들며 사라지고 공동 자금에 반영
```

## 1. 판매대 — 올려두기

`OfficeSaleCounter`

- F를 누르면 선택 중인 회수품을 판매대 윗면의 **빈 자리**(0.42m 간격 격자)에 내려놓는다.
- 놓인 물건은 일반 월드 물체라 **F로 다시 집을 수 있다.**
- 사무소 바닥 물건과 같은 방식으로 처리되어 저장·사무소 재방문 때도 그 자리에 남는다.
- 판매대가 가득 차면 "판매대가 가득 참 — 벨을 눌러 판매"라고 안내한다.
- `CollectPlacedItems()` 판매대 위 미판매 회수품 목록 · `Sell()` 고른 물건 판매

**크기 변형 방지** — 판매대는 배율(2.6 × 1.3 × 1.25)이 걸린 상자라, 그 자식으로 거쳐 간 물건은 내려놓을 때 크기가 늘어난다. 배율이 없는 씬 최상위 임시 루트를 거쳐 내려놓도록 했다.

## 2. 판매 벨

`OfficeSaleBell` · `Day32_SaleBell` (판매대 오른쪽, 나무 받침대 + 놋쇠 벨)

- F를 누르면 벨이 흔들리고, 판매대에 물건이 있을 때만 선택 창이 열린다.
- 안내 문구에 올린 물건 수와 최대 판매 금액을 보여 준다.

## 3. 판매 선택 창

`OfficeSalePanel` (정식 HUD 전까지 즉시 모드 GUI)

```text
판매할 물건을 고르세요
[전체 선택] [전체 해제]
[v] 은 동전          437
[v] 장인의 금속 장식  563
[ ] 왕관            2250
선택 2개 / 합계 1000   (공동 자금 2400)
[판매 (1000)]  [취소]
```

- 기본값은 전부 선택, 선택이 없으면 판매 버튼 비활성
- 창이 열린 동안 커서 표시 · 이동과 F 입력 정지 · Esc로 취소
- 판매 즉시 판매 완료 기록과 자금 반영 → 0.35초 동안 줄어들며 떠오른 뒤 사라짐 (그동안 다시 집을 수 없음)

## 4. 배치 도구

```text
Project I > Day 32 > Add Sale Bell To Office
```

판매대의 네 옆면 중 막히지 않은 쪽을 골라 벨을 세운다. 처음 버전은 겹침 검사 상자가 바닥 두께까지 닿아 네 면 모두 막힘으로 판정했고(결과적으로 기본값인 오른쪽에 배치), 검사 상자를 바닥 위로 올려 수정했다.

## 검증

에디터 플레이 테스트:

```text
은 동전 · 장인의 금속 장식 · 왕관 판매대에 올림 (최대 5개 동시)
선택 창에서 골라 판매 → 은 동전 +437 · 장식 +563 · 왕관 +2250 등 금액 반영
예외 없음
```

검증 하네스:

- 신규 단계 **BS**: 벨 없으면 창 안 열림 → 올려도 안 팔림 → 크기 유지 → 다시 가져가기 → 두 개 다른 자리 → 취소 → 하나만 골라 판매 → 남은 것 판매 → 판매대 비움
- 기존 A · F1 · 27일차 단계의 판매 과정을 "올리기 → 벨 → 판매"로 변경
