# 43일차 — 음성 채팅 · Esc 원정대원 패널

## 이번 일차 목표

게임 안에서 **가까운 원정대원 목소리가 그 대원 위치에서 들리게** 만든다. Esc 화면 오른쪽에는 대원 목록·음량·음소거·강퇴를 모은다.

```text
내 마이크 → (Steam 음성 또는 유니티 마이크 + μ-law) → 내 몸체 → 방장
방장: 듣는 조건 판정 (같은 맵 40m · 쓰러짐 규칙) → 해당 대원에게만 전달
대원: 버퍼(100ms) → 말한 대원 입 위치 3D 재생 → 벽 너머면 먹먹하게
```

## 1. 압축·버퍼 — `VoiceCodec.cs`

| 구성 | 내용 |
| --- | --- |
| `VoiceCodec` | 16kHz · 20ms(320표본). μ-law 8비트 압축·해제(해제 표 256개), 16비트 PCM 변환, 소리 크기(RMS), 선형 보간 주파수 변환 |
| 코덱 번호 | `0` 유니티 마이크 + μ-law / `1` Steam 음성 · 한 조각 최대 2KB |
| `VoiceRingBuffer` | 잠금이 있는 원형 버퍼. 넘치면 오래된 표본부터 버림 · `TrimTo`로 지연 줄이기 |
| `VoicePreferences` | 대원별 음량(0~200%)·음소거를 내 컴퓨터에만 저장. 키는 Steam ID(`s…`), 없으면 이름(`n…`) |

## 2. 녹음 — `VoiceCapture.cs`

- 게임 시작 시 유지 오브젝트 `===ProjectI Voice===`를 만든다.
- 녹음 조건: 음성 켜짐 · 마이크 끔 아님 · (협동 게임 중 또는 마이크 시험)
- **Steam이 있을 때**
  - `StartVoiceRecording`·`GetVoice`(압축)를 쓰고, 말소리 감지·압축은 Steam이 한다.
  - 조각을 모아 50ms마다(초당 20번) 보낸다.
  - 내 음성을 해제해 입력 크기를 표시하고 마이크 시험에 쓴다.
- **Steam이 없을 때**
  - `Microphone`을 1초 원형으로 녹음한다(설정 장치, 없으면 기본 장치).
  - 마이크 음량을 곱한 뒤 16kHz로 바꾸고, 40ms 묶음으로 μ-law 압축해 보낸다(초당 25번).
- 말하기 방식
  - **`V` 누르고 말하기**(기본)
  - **항상 켜기**: 크기가 감지 기준을 넘으면 0.4초 유지하며 보낸다.
- **마이크 시험**(`LoopbackTest`): 보내지 않고 2D 재생기로 바로 들려준다.

## 3. 전달 — `NetPlayerAvatar.Voice.cs` (partial)

- 원정대원 몸체(이미 있는 플레이어 프리팹)에 음성 RPC를 추가했다 → **네트워크 프리팹 재생성 불필요**.
- `VoiceUpRpc`: 비신뢰 전송, `InvokePermission = Owner`(몸체 주인만 보낼 수 있음).
  - 방장은 보낸 대원 = 주인인지 확인한다.
  - `NetGuard` 새 종류 `Voice`: 초당 40번·순간 80번이고, 초과는 경고 0.25씩이다.
  - 크기(1~2KB)와 코덱 번호를 검사한다.
- `RelayVoice`: 방장이 대원마다 **들을 수 있는지** 판정한다.

| 말하는 대원 | 듣는 대원 | 전달 |
| --- | --- | --- |
| 쓰러짐 | 쓰러짐 | O (거리 무관) |
| 쓰러짐 | 생존 | X |
| 생존 | 쓰러짐 | O (거리 무관) |
| 생존 | 생존 | 같은 맵 · 40m 안 (몸체가 보낸 위치 기준) |

- `VoiceDownRpc`: 비신뢰 전송, `SendTo.SpecifiedInParams`로 대상에게만 보낸다. 보내기는 방장만 할 수 있다.
- 받은 쪽은 음성이 꺼져 있거나 그 대원을 음소거했으면 버린다.
- 몸체 주인은 `steamId`를 기록한다(음량 저장 키). 말하는 중이면 이름표에 `♪`가 붙는다.
- 0.25초마다 재생 설정을 갱신한다: 설정 음량 × 대원별 음량. 쓰러짐이 섞이면 2D(거리 없이)로 바꾼다.

## 4. 재생 — `VoicePlayback.cs`

- 몸체 입 위치(1.6m)의 `AudioSource`다. 선형 감쇠로 2m까지 최대, 30m에서 0이고, 도플러는 끈다.
- **1.0으로 채운 반복 소리 × `OnAudioFilterRead`**
  - 유니티가 계산한 3D 음량·방향이 들어간 1.0에 음성 표본을 곱한다.
  - 오디오 스레드에서 16kHz → 출력 주파수로 선형 보간한다. 버퍼에서 512개씩 꺼내고, 남은 표본은 다음 콜백에서 이어 쓴다.
- 100ms가 모이면 재생을 시작하고, 바닥나면 다시 모은다. 300ms 넘게 밀리면 150ms로 줄인다.
- 0.2초마다 귀 → 입 선분 검사를 한다. 말하는 대원 몸체 말고 다른 것에 막히면 **저역 통과 1100Hz + 음량 55%**를 적용한다.
- Steam 조각은 `DecompressVoice`(16kHz)로 해제한다.

## 5. 화면

### Esc — 오른쪽 원정대원 패널 (`CrewPanel` 다시 작성)
- 42일차에 따로 뜨던 창 대신, 협동 중에는 **Esc 화면 오른쪽에 항상 표시**한다(880×820). 설정을 열면 숨긴다.
- **맨 위**: `원정대원 n/4`, 방장에게만 `방 잠그기 [ ]`
- **내 줄**: 이름 [방장] (나) · 지연 / 마이크 크기 막대 · `마이크 끄기·켜기`(설정에서 꺼져 있으면 `음성 꺼짐 (설정)`)
- **다른 대원 줄**
  - 윗단: 이름 · `♪ 말하는 중`/`쓰러짐` · 지연
  - 아랫단: `음량` 슬라이더(0~200%) · 값 · `음소거`/`소리 켜기`, 방장에게만 `내보내기` `차단`(두 번 눌러 실행, 대기 중 `확인?` 빨강)
  - 음소거한 대원 줄은 흐리게 표시한다.
- **빈 자리 줄**: `빈 자리 — 코드 K7Q-2MX`(잠기면 잠김 안내)
- 목록·잠금·코드가 바뀔 때만 다시 그리고, 말하기·지연·마이크 막대는 제자리에서 갱신한다 → 슬라이더를 끄는 도중에 끊기지 않는다.
- 왼쪽 메뉴: `원정대원` 버튼을 없앴고, 코드 복사 → 친구 초대 순서로 바꿨다.
