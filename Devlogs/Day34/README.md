# 34일차 — 거점 마을 (빅토리아 산업 도시 양식) · 뒷골목 · 훈련장 · 글자 가림 수정

## 이번 일차 목표

사무소 씬(`01_Office`)을 **마을 하나**로 다시 구성한다. 한 건물에 모여 있던 기능을 건물별로 나누고, 뒷골목을 지나면 기존 테스트 기능이 있는 훈련장이 나온다.

```text
                 ┌───────── 북쪽 광장 (우물) ─────────┐
  [빈 점포 NW]   │                                    │   [빈 점포 NE]
  [상점]         │  ══ 도로 ══                        │   [보관 창고] ── 뒷골목 ──▶ 훈련장
  [사무소]  ◀ 시작 위치                               │   [판매소]
                 │        [마차 정차]                 │
                 └────────── "거점 마을" 아치 ─────────┘
```

- 게임 시작 시 **사무소 앞**에서 시작한다.
- 마차는 마을 남쪽 도로에 선다. 마차는 남쪽 아치로 들어온다.
- 뒷골목(보관 창고와 빈 점포 사이)은 훈련장의 서쪽 경계에 뚫린 문으로 이어진다.

## 1. 건물과 기능 배치

| 건물 | 기능 | 양식 |
| --- | --- | --- |
| 사무소 | 공동 자금 · 채무 장부 · 하루 마감 | 붉은 벽돌 3층, 석재 문틀·삼각 박공, 놋쇠 명판, 벽난로 |
| 상점 | 33일차 2칸 진열대 · 수령대 | 붉은 벽돌 3층, 녹색 상점 정면, 줄무늬 차양 |
| 판매소 | 32일차 판매대 · 판매 벨 | 누런 벽돌 2층, 적갈색 상점 정면 |
| 보관 창고 | 보관 단상 6개 (2×3) | 그을린 벽돌 3층, 아치 하역문, 도르래 들보, 벽 글씨 |
| 빈 점포 2채 | 기능 없음 — **문은 열려 있음** | 천 덮인 가구 · 사다리 · "임대 문의" 안내 · 진열창 신문지 |

- 기능 오브젝트는 먼저 임시 보관한 뒤 마을을 새로 짓고 각 건물 실내로 옮긴다. 메뉴를 여러 번 실행해도 기능과 연결이 유지된다.
- 상점 진열대는 33일차 배치 도구의 `Day34Layout`(건물 뒷벽 기준)으로 다시 만든다.

## 2. 산업혁명기 영국 분위기

`Editor/Town/` 모듈식 제작 도구

| 파일 | 내용 |
| --- | --- |
| `TownKit` | 기본 도형 · 재질 · 3D 글자 · 조명(게임 밝기 연동) · 실내 영역 · 구멍 뚫린 벽 · 굴뚝 연기 파티클 · 박공용 삼각기둥 메시 |
| `TownPalette` | 벽돌 3종 · 석재 · 슬레이트 · 납 · 주철 · 도장색 · 창 · 차양 · 벽지 · 돌길 등 재질 |
| `TownBuilding` | 연립 건물: 정면 양식 3종(상점/사무소/창고), 층수·지붕 경사·도머·빈 점포 옵션 |
| `TownProps` | 가스 가로등 · 주철 난간 · 원통 우체통 · 말뚝 · 공장 굴뚝 · 제철소 · 벽돌 담 · 아치 · 거리/실내 소품 |

- **외관:** 모서리돌, 층 띠, 톱니 장식 처마, 오르내리창(창 위 석재·이맛돌), 슬레이트 지붕과 지붕보다 솟은 박공, 굴뚝 단지, 물받이·선홈통, 위층 일부 불 켜진 창
- **실내:** 벽지와 징두리 판벽, 천장 몰딩, 가스 샹들리에(실내 영역 자식으로 두어 실내 밝기로 판정)
- **거리:** 돌길 도로와 판석 보도, 웅덩이, 옆벽의 바랜 광고 글씨
- **마을 밖:** 톱니 지붕 제철소, 연기 나는 공장 굴뚝 3개

## 3. 시작 위치

- `MapTravelAnchor`에 `playerSpawnPoint` 추가
- `PersistentMapLoader`: 첫 부팅과 저장 복원 시 마차와 함께 옮긴 뒤, 플레이어가 마차에 타고 있지 않으면 시작 위치로 이동(CharacterController를 잠시 끄고 위치·방향 설정)
- `Day23SnapshotBridge`: 보관 단상 경로가 바뀌어 저장된 경로를 찾지 못하면, 이름이 같은 빈 단상에 복원

## 4. 벽 너머로 비치는 글자 수정

TextMesh 기본 글꼴 재질은 깊이 검사를 하지 않아 벽 뒤 간판·가격표·라벨이 비쳐 보였다.

- 깊이 검사 글자 셰이더 `Art/Shaders/TextMeshDepth.shader`와 재질 `Resources/Text/TextMeshDepth.mat` 추가
- `TextMeshDepthFix`: 게임 시작과 씬 로드마다 모든 TextMesh 재질 교체, 동적 글꼴 텍스처 갱신 추적
- `TextMeshDepthFixTool`: 에디터 화면에서도 적용, 마을·상점 가격표·12일차 라벨 생성 코드에 적용, 모든 씬 일괄 적용 메뉴
