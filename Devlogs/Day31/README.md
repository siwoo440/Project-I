# 31일차 — 전력 계통·다층 이동·지하묘지 프리셋 → 싱글 수직 슬라이스

```text
연결성 · NavMesh · 열쇠 진행 검사 → 지하묘지 1,000시드
```

## 1. 전력 계통

`Scripts/Generation/Power/`

| 구성 | 역할 |
| --- | --- |
| `DungeonPowerGrid` | 던전 전체 전력망. 발전기 1대 + 구역 여러 개 |
| `DungeonPowerZone` | 배전 구역. 발전기 가동 **그리고** 차단기 켜짐일 때만 전기 공급 |
| `DungeonPowerPlant` | 발전실의 발전기. F로 기동·정지 |
| `DungeonBreaker` | 배전반의 차단기. 자기 구역만 켜고 끔 |
| `DungeonPowerConsumer` | 조명 등 전기를 쓰는 물건. 정전 시 비상등으로 전환 |
| `DungeonElevator` / `DungeonElevatorButton` | 전력 승강기와 버튼 |

배치 규칙 (`SocketDungeonPlanner`):

```text
발전실      시작 방에서 깊이 2 이상
배전반      구역마다 1개, 구역 안에 배치
구역 나누기  모든 모듈을 가장 가까운 배전반 기준으로 3개 구역에 배정
잠긴 문     발전실·배전반이 잠긴 문 너머에만 있게 되면 잠그지 않음
```

방마다 조명이 자동으로 달리고, 자기 구역 전기가 끊기면 꺼진다.

## 2. 다층과 층 이동

모듈을 **바리에이션 프리팹**으로 나눠, 사다리·버튼·승강기 판 위치를 프리팹 안에 고정했다. 생성 중에 위치를 계산하지 않으니 벽에 묻히거나 문을 가리는 일이 없다.

```text
Vertical/
  계단통   Stairwell_5x13 · Stairwell_7x13 · Stairwell_5x13_E
  사다리   Ladder_5x5_W · Ladder_5x5_E · Ladder_5x7_W   (반드시 벽면을 따라)
  승강기   Elevator_7x7_3 · Elevator_7x7_2 · Elevator_9x9_3 (정차 층 수)
```

**승강기**

```text
3x3 직육면체 승강로 + 층마다 승강장
판은 바닥에서 0.03m 띄워 겹치지 않음
판 안 버튼   층 수만큼 → 누르면 그 층으로 이동
호출 버튼   층마다 문 옆 → 누르면 판이 그 층으로 옴
탑승자      판 영역 안의 플레이어를 함께 옮기고 착지 처리
전기        구역에 전기가 없으면 버튼이 반응하지 않음
```

## 3. 수정 사항

- 문이 **플레이어가 바라보는 방향**으로 밀려 열림
- 모듈과 출입구 폭을 1/3 축소 (2.40m → 1.60m)
- 서브문이 시작 방이나 그 옆에 생기지 않게 깊이 5 이상 · 서브문끼리 4칸 이상 간격
- 사다리를 벽면 안쪽 0.02m 앞에 세워 보이게 함 (이전에는 벽 속에 묻혀 있었음)
- 옛 크기 프리팹 25개 삭제 (모듈 목록 참조 0 확인 후)

## 5. 이번 일차에 잡은 버그

**승강기가 작동하지 않음** — 버튼 클래스를 `DungeonElevator.cs` 안에 함께 넣었는데, 유니티는 프리팹에 저장되는 컴포넌트를 **클래스 이름과 같은 파일**에서만 찾는다. 프리팹의 버튼 스크립트가 비어 있어 게임에서 버튼이 없었다. `DungeonElevatorButton.cs`로 분리했고 같은 구조였던 `DungeonPowerZone`도 분리했다.

**30일차 커밋에 모듈 목록이 빠짐** — 폴더 이름이 `Library`라서 `.gitignore`의 `[Ll]ibrary/`(유니티 캐시용 규칙)에 걸렸다. 원격 저장소를 새로 받으면 던전이 생성되지 않았다. `ModuleLibrary`로 이름을 바꿔 이번 커밋에 포함했다. meta째 옮겨 씬 참조는 그대로다.

**승강기 판이 바닥에 파묻힘** — 판 두께 중심을 원점에 둬서 0.19m 내려가 있었다. 판을 원점 위로 올림.

**잠긴 문이 배전반을 막음** — 600시드 중 518개에서 배전반이 잠긴 문 너머에 있었다. 잠그기 전에 발전실·배전반 도달을 확인.

**배치 코어의 유니티 의존** — 순수 C# 어셈블리에서 `Mathf`를 써서 제거.
