# 36일차 — 정식 HUD · 창 모양 통일 · 합성 소리 · Windows 알파 빌드 메뉴

## 이번 일차 목표

혼자서 처음부터 끝까지 플레이할 수 있는 **싱글 알파**의 마감 작업.

- 흩어져 있던 개발용 화면 표시를 메뉴와 같은 주황 단말기 모양의 **정식 HUD**로 정리한다.
- 판매 선택 창·구매 창을 같은 모양으로 옮긴다.
- 음원 파일 없이 **코드로 합성한 소리**를 넣고 설정 창 음량과 연결한다.

## 1. 정식 HUD — `GameHud`

핵심 루트(`===ProjectI Core===`)에 붙는다. 플레이어가 있을 때만 보이며, Boot·메인 메뉴에서는 숨는다.

```text
┌ 5일차 · 출발 준비 ─────┐        상점에서 장비를 사고, 마차 창고 안의 종으로 출발하세요
│ 14:30  낮               │        ┌ 원정 결과 — 귀환 6개 · 새 회수품 4개 (가치 820) … ┐
│ 공동 자금  1,250        │
│ 채무  2단계 · 남은 800  │                     ┼
└─────────────────────────┘             [ [F] 판매 벨 울리기 ]
                                          ( 구매 완료 — 수령대에서 가져가세요 )
[ 체력  80 / 100 ]
[ 기력  64 / 100 ]              [1][2][3][4][5][6]
```

| 영역 | 내용 |
| --- | --- |
| 왼쪽 위 | 일차·단계, 시각·시간대, 공동 자금, 채무 단계와 남은 금액 (사무소를 떠나 데이터가 없으면 마지막 값) |
| 위 가운데 | 단계별 할 일 안내, 귀환 후 원정 결과(실패 시 잃은 물건) |
| 가운데 | 주황 조준점(조작 중일 때만), `[F] …` 조사 안내, 길게 누르기 진행 막대 |
| 왼쪽 아래 | 체력·기력 막대 (탈진 시 기력 빨강) |
| 가운데 아래 | `GameHud.ShowNotice` 짧은 알림 |
| 빠른 슬롯 | 기존 `QuickSlotHud`를 주황 모양으로 바꿈, 잠금 표시 `LOCK` → `양손` |

정리한 예전 표시 (OnGUI 제거):

- `PlayerDebugHud` 체력·기력 막대와 조준점 (F1 디버그 페이지는 유지)
- `InteractionPromptHud` 조사 안내
- `ExpeditionReportTracker` 일차·결과 상자 (단계 이름·안내 문구 함수는 HUD용으로 공개)

## 2. 창 모양 통일

| 창 | 새 모양 |
| --- | --- |
| 판매 선택 `OfficeSalePanel` | 줄을 눌러 `[X]` 선택 · 전체 선택/해제 · 합계와 자금 변화 · `판매 (합계)` · 취소 |
| 구매 `OfficeShopPanel` | 상품명 · 단가 · `-` 수량 `+` · 최대/한도 · 합계 · 자금 변화 · 질문(불가 이유는 빨강) · 구매/취소 |

- 검증 도구가 쓰는 API(`Open`, `SetSelected`, `ConfirmSale`, `SetQuantity`, `Confirm`, `Close`, `LastSaleTotal`, `LastDelivered` 등)는 그대로다.
- Esc 처리(커서 잠금으로 닫힘)도 그대로다. 구매 성공 알림은 HUD 알림으로 나온다.

## 3. 소리 — `Scripts/Audio`

프로젝트에 음원이 없어 **모두 코드로 합성**한다 (22050Hz 모노, 처음 요청할 때 만들어 캐시). 외부 음원을 쓰지 않아 출처 문제가 없다.

| 종류 | 소리 |
| --- | --- |
| 메뉴 | 강조 · 선택 · 불가 |
| 플레이어 | 발소리 돌/나무/흙 (각 3가지 변형) · 착지 · 줍기 · 내려놓기 |
| 사무소 | 판매 벨 · 판매(종 + 동전) · 구매(동전) |
| 원정 | 마차 종 · 던전 문 열림/닫힘/잠김 |
| 반복 | 메인 메뉴 음악(Am–F–C–E 화음 + 오르골, 16초) · 바람 · 공장 기계음 · 던전 울림 |

- `SoundPlayer`: 재생기 24개를 재사용한다. 화면 소리와 위치 소리를 지원하고, 편집 모드에서는 재생하지 않는다.
- `AmbientLoop`: 반복 소리를 서서히 키우고, 설정 음량이 바뀌면 바로 반영한다.
- `FootstepAudio`: 이동 거리로 걸음을 세고, 발밑 오브젝트·재질 이름으로 바닥을 구분한다.
- `SceneAudioInstaller`: 씬이 열릴 때 자동으로 붙인다 (씬 파일 수정 없음).
  - 메인 메뉴: 음악 + 바람 + 굴뚝
  - 마을(`01_Office`): 바람 + 굴뚝마다 기계음
  - 던전 계열: 울림
  - 플레이어: 발소리
- 설정: 음악 · 효과음 · 환경음 음량을 추가했다 (전체 음량은 AudioListener).

## 4. Windows 알파 빌드 — `Phase15Day36WindowsBuild`
