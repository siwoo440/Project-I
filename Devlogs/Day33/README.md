# 33일차 — 사무소 상점 (2칸 진열대 · 수량/구매 확인 · 수령대)

## 이번 일차 목표

사무소 구성을 본격적으로 하기 전에 **상점 기능**부터 만든다. 마트처럼 진열대에 놓인 상품을 골라 수량을 정하고 구매한다.

```text
진열대 칸의 상품을 보고 F
→ 구매 창: 상품명 / 개당 가격 / 수량 [-] n [+] (지금 최대 n개) / 합계 / 자금 변화
           "손전등 3개를 구매하시겠습니까?"   [구매] [취소]
→ [구매]: 공동 자금에서 결제 → 진열대 옆 수령대에 실제 물건이 놓임 → F로 집어 감
```

## 1. 진열대 — 위·아래 2칸

`Day33_Shop/Shelf` (사무소 남쪽 벽, 폭 3.2m · 높이 1.75m)

| 칸 | 상품 (가격 / 한 번에 최대) |
| --- | --- |
| 위 | 손전등 120/5 · 열쇠 200/5 · 회복 아이템 150/5 · 작은 도구 60/5 |
| 아래 | 곡괭이 180/3 · 검 250/3 · 석궁 400/3 · 6연발 리볼버 650/3 |

- 칸마다 **실제 아이템 모양의 견본**을 왼쪽부터 진열한다. 원본 프리팹을 복사한 뒤 스크립트·물리·충돌·조명을 제거해 집을 수 없게 만든다.
- 세워진 긴 물건은 눕히고, 앞뒤로 긴 물건은 폭 방향으로 돌린 뒤 칸 크기에 맞게 줄인다. 너무 작은 물건(열쇠 등)은 보이도록 키운다.
- 칸 앞 가격표에 가격을 표시한다. 3D 글꼴의 한글 누락을 피하려고 숫자만 쓴다.
- 칸 전체에 조사 판정을 두어 칸 어디를 봐도 `손전등 / 120 — 구매하기`가 뜬다.

## 2. 구매 창

`OfficeShopPanel`

- 수량 기본값 1, [-] [+]로 1 ~ 상품 한도 사이에서 조절
- **지금 최대 수량** = 상품 한도 · 남은 자금 · 수령대 빈 자리 중 가장 작은 값
- 살 수 없으면 이유("자금이 부족합니다" / "수령대 자리가 부족합니다")를 보여 주고 구매 버튼을 끈다.
- 구매에 성공하면 창을 닫고 "구매 완료 — 수령대에서 가져가세요"를 잠깐 띄운다.
- [취소] 또는 Esc로 닫는다.

## 3. 수령대

`OfficeShopPickupTray` (진열대 오른쪽, 0.9 × 0.6m, 빈 자리 6칸)

- 결제 **전에** 빈 자리를 확인해, 결제만 되고 물건이 안 나오는 일을 막는다.
- 산 물건은 아이템 정의의 프리팹으로 생성하고 새 개별 ID를 붙여 **사무소 씬에 소속**시킨다. 사무소 바닥 물건과 같은 방식으로 저장·원정 왕복 보관이 처리된다.
- 일부만 생성되면 차액을 환불한다.

## 4. 공용화

| 공용 코드 | 사용처 |
| --- | --- |
| `OfficeSurfaceSlots` — 윗면 빈 자리 찾기 · 윗면 위 물건 목록 | 판매대 · 수령대 |
| `PlayerControlLock` — 창이 열린 동안 이동·F·슬롯 입력 정지, 커서 표시 | 판매 선택 창 · 구매 창 |

`PlayerControlLock`은 한 번에 창 하나만 열리게 한다. 창이 닫히지 않고 파괴돼도(씬 이동 등) 다음 호출에서 조작을 복구한다.

## 검증

```text
배치          진열 8종 (위 4 · 아래 4) · 겹침 경고 없음
              진열대 (51.20, 0.20, 0.91) · 수령대 (53.45, 0.20, 0.96)
컴파일        에디터 밖 dotnet 빌드 — 게임·에디터·하네스 오류 0
플레이        에디터에서 직접 확인
```

검증 하네스 신규 단계 **SH** (작성 완료, 실행 대기):

```text
SH1 2칸 진열 · 위 칸이 더 높음 · 왼쪽부터 정렬 · 견본에 기능 없음 · 가격표
SH2 창 열림 · 조작 정지 · 다른 상품 안 열림 · 수량 1~한도 · 취소 시 변화 없음
SH3 3개 구매 결제 · 수령대 3개 · 사무소 소속 · 고정 ItemId + 서로 다른 InstanceId · 줍기
SH4 자금 부족이면 거부하고 창 유지
SH5 자리보다 많으면 결제 전 거부 · 남은 자리만큼 구매 · 가득 차면 최대 0
SH6 원정 왕복 후 수령대 물건·자금 유지 · 중복 없음
```

- 상점 재고·해금 일차, 정식 HUD로 창 이전
