# 30일차 — 소켓 기반 모듈 던전 (리썰 컴퍼니 방식) 전환

## 이번 일차 목표

격자 위에 방을 채우던 생성 방식을, **방 프리팹의 출입구(소켓)끼리 맞춰 붙이는 방식**으로 바꾼다. 리썰 컴퍼니가 쓰는 DunGen과 같은 접근이다.

```text
이전  9m 격자에 방을 채움 → 방이 전부 네모반듯, 크기도 칸 배수
이후  방 프리팹을 만들어 출입구에 표시를 붙이고, 표시끼리 맞춰 이어 붙임
      → 모양이 자유롭고, 방 외형을 프리팹으로 직접 디자인할 수 있음
```

## 결과 요약

```text
모듈 프리팹    방 10종 · 복도 6종 · 세로형 2종 · 문 5종 = 23개
출입구 규격    2.40 x 2.80m (모든 모듈 공통)
연결 상태      문 있음 / 문 없음 / 벽으로 막힘
복층           1F 기준 위로 2층, 아래로 2층 (B2 ~ 3F)
검증           배치 600시드 · 실제 생성 12시드 · Play 모드 17단계
```

## 1. 모듈 세트

형태를 칸(1m) 단위로 정의하면 바닥·천장·바깥 벽·문틀·출입구 표시가 자동으로 만들어진다. ㄱ·T·십자·ㄷ자처럼 네모가 아닌 모양도 바깥 경계를 찾아 벽을 세운다.

```text
Assets/ProjectI/Prefabs/Dungeon/
  Rooms/      Entrance_13x13 · Square_7x7 · Hall_11x11 · Wide_13x7
              L_11x11(ㄱ자) · T_13x11(T자) · Cross_13x13(십자) · U_13x11(ㄷ자)
              Boss_19x19 · Secret_9x9
  Corridors/  Short_3x5 · Straight_3x9 · Long_3x15
              Corner_9x9(ㄱ자) · T_11x7(T자) · Cross_11x11(십자)
  Vertical/   Stairwell_7x13 (계단 32.7°) · Ladder_5x7 (사다리)
  Doors/      Door_Standard · Door_Locked · Wall_Breakable · Door_Exterior · Wall_Plug
  Library/    DungeonModuleLibrary.asset
```

형태를 정의할 때 **구멍 폭이 들어갈 벽 길이가 확보되는지, 출입구끼리 너무 가깝지 않은지**를 자동 검사한다. 규격이 어긋나면 프리팹을 굽지 않는다.

## 2. 배치 엔진

`SocketDungeonPlanner` (순수 C#, 유니티 비의존)

```text
1. 시작 방 배치
2. 빈 출입구를 하나 골라 (깊은 쪽 선호)
3. 후보 모듈의 출입구가 마주 보도록 회전·이동을 계산
4. (칸, 층) 점유를 확인해 겹치면 다음 후보
5. 목표 수까지 반복 → 순환로 연결 → 보스방·비밀방 → 채움 결정 → 남은 출입구 봉인
```

- 세로형 모듈은 한 칸을 **두 층에 걸쳐** 차지한다. 위층 출구로도 붙일 수 있어 올라가는 방향과 내려가는 방향 모두 층이 생긴다.
- 연결마다 채움을 기록한다: 뚫림 / 여닫이문 / 잠긴 문 / 금 간 벽 / 외부 문.

## 3. 문

모든 모듈이 같은 구멍 규격을 쓰므로 문이 어디에나 들어간다.

| 상태 | 생성물 |
| --- | --- |
| 문 있음 | 문틀 + 문짝 (`DungeonDoor`, F로 열고 닫음. 플레이어 반대쪽으로 열림) |
| 문 없음 | 문틀만 |
| 벽으로 막힘 | 문틀 숨김 + `Wall_Plug` |

잠긴 문은 열쇠를 소모해야 열리고, 그 뒤로는 일반 문처럼 여닫힌다.

## 4. 게임 루프 연결

```text
Start()              씬 로드 직후 캠페인·일차 시드로 자동 생성
ResolveSeed()        같은 캠페인·일차·지역이면 같은 던전
CollectExteriorDoors 외부 씬 문 수집 → 정문 1 + 서브문 번호 연속 검사
exteriorDoorCount    외부 서브문 수를 읽어 실내 서브문을 같은 수로 생성 (1:1 규칙)
UseDoor / FindDoor   짝이 되는 문으로 순간이동
회수품·열쇠           깊이별 등급 배치 · 열쇠는 잠긴 문 앞쪽 가장 깊은 방
```

`DungeonTeleportDoor`는 모듈 생성기가 있으면 그쪽으로, 없으면 이전 격자 생성기로 간다. 두 방식을 메뉴로 오갈 수 있다.

```text
Project I > Day 30 > Use Module Dungeon In Test Dungeon
Project I > Day 30 > Revert To Grid Dungeon
```

## 5. 이번 일차에 잡은 버그

**방 한가운데를 가로막던 벽** — 벽 길이 방향 벡터의 부호를 무시하고 비교해서 남쪽 벽만 90° 돌아갔다. 29일차 모듈 전환에서 이미 고쳤지만, 같은 부류의 문제를 구조적으로 막기 위해 면마다 자기 좌표계를 갖게 했다.

**회전한 모듈이 한 칸씩 어긋남** — 칸 번호를 90° 회전할 때 `(x,y) → (-y, x)`로 계산했으나, 칸은 점이 아니라 1m 정사각형이라 `(-y-1, x)`가 맞다.

**밖이 보이는 틈** — 프리팹에는 출입구 구멍이 미리 뚫려 있는데, 짝이 없는 출입구를 데이터상 "봉인"으로만 표시하고 실제 벽을 세우지 않았다. 시드당 평균 37개가 뚫린 채였다. `Wall_Plug`로 막고, 방 안에서 사방 160방향으로 광선을 쏴 하나라도 밖으로 나가면 실패로 처리하는 검사를 넣었다.

**이어지지 않는데 문틀만 있던 곳** — 봉인된 출입구에서 문틀까지 숨겨 통짜 벽으로 보이게 했다.

**출입구 기즈모가 90° 틀어져 보임** — 기즈모를 월드 축으로 그려서 동·서 출입구에서 가로/세로가 뒤바뀌었다. 소켓 방향 기준으로 수정.

**모듈 목록이 씬에 저장되지 않음** — 에디터 스크립트가 에셋을 먼저 불러오고 씬을 Single 모드로 열었는데, 그 전환에서 유니티가 참조 없는 에셋을 언로드해 참조가 무효화됐다. 씬을 연 뒤에 불러오도록 변경.

**ㄷ자 방 중심점이 형태 밖** — 칸 평균이 빈 구역에 떨어졌다. 평균에서 가장 가까운 실제 칸으로 보정.

**바닥에 붙은 물건의 층 판정** — `y`가 미세하게 음수가 되어 한 층 아래로 판정됐다. 0.2m 여유 추가.

## 검증

```text
모듈 형태 규격      23종 자동 검사 (구멍 폭·출입구 간격)
배치 검사           시드 600개 전부 성공 · 평균 모듈 28개 · 평균 층 3.2개
                    칸 겹침 0 · 전 모듈 도달 가능 · 출입구 양쪽 정합
실제 생성 검사      시드 12개 · 출입구 월드 오차 0.01m 이내 · 밖으로 새는 광선 0
EditMode            24 / 0
```

Play 모드 회귀 17단계 전부 통과:

```text
A 137/0  B 43/0  C 10/0  D 8/0  E 29/0  F1 52/0  F2 26/0  F3 5/0
G 27/0   G2 55/0  H 22/0  L 5/0  FD 5/0  S 9/0   N 53/0  M 65/0
```

- 단계 M (신설): 모듈 던전 생성 · 복층 · 계단 보행 · 사다리 등반 · 문 3상태 · 보스방/비밀방 · 회수품/열쇠 · 정문 왕복
- 단계 G·N: 격자/모듈 두 방식 공용으로 수정
- 단계 S: 격자 전용이므로 모듈 방식 씬에서는 건너뜀

계단·사다리 실측:
```text
계단 기울기 32.7° ≤ 이동 한계 50°
앞으로 가는 키만으로 B2 → B1 올라감 / 같은 계단으로 내려옴
F로 사다리 타기 → W로 B1 → 1F 올라가 바닥에 내림 → S로 내려옴
```
