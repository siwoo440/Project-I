# 37일차 — 협동 기초: Netcode 방 만들기·참가 · 원정대원 동기화 · 방장 기준 월드 동기화

## 이번 일차 목표

혼자 하던 게임을 **여러 명이 같은 세계에 들어오는 협동 게임**으로 바꾸기 시작한다.

```text
방장: 메인 메뉴 → 서버 → [ 방 만들기 ] → 자기 저장으로 게임 시작 → 방 열림 (포트 7777)
참가: 메인 메뉴 → 서버 → 주소 127.0.0.1 : 7777 → [ 주소로 참가 ] → 연결되면 사무소 마을로
함께: 서로의 몸체가 보임 → 모두 마차에 타고 종 → 같은 던전 → 문이 함께 열림 → 함께 귀환
```

아이템·경제(38일차), 전투·AI·함정(39일차), Steam 로비(40일차)는 다음 일차에서 연결한다.

## 0. 패키지와 빌드

- `com.unity.netcode.gameobjects` **2.13.2** 추가 (Unity 6용 최신 안정판, Transport 2.6.0 자동 포함). 3.0.0은 Unity 6000.7 이상이 필요해 제외했다.
- Unity 밖 확인: 패키지 원본을 받아 Transport·Netcode 본체를 dotnet으로 빌드한 뒤, 그 DLL로 새 코드를 미리 컴파일했다 (오류 0).
- 36일차 Windows 알파 빌드 성공: 127.1MB, 오류 0, `Boot → MainMenu → 00_WagonPersistent → 01_Office → 02_TestDungeon`

## 1. 방 관리 — `NetworkSession`

`Resources/Net/ProjectINetwork` 프리팹(NetworkManager + UnityTransport + NetworkSession)을 처음 필요할 때 생성한다.

| 기능 | 내용 |
| --- | --- |
| 방 만들기 | 방 열기를 예약하고 게임 월드를 불러온다(이어하기 저장, 없으면 1일차). 맵 로더와 저장이 준비되면 `StartHost`, 월드 상태를 생성한다. 실패하면 혼자 하기로 진행한다. |
| 주소로 참가 | `StartClient` → 연결되면 게임 월드를 불러온다. **참가자는 자기 저장을 읽거나 쓰지 않는다.** |
| 접속 확인 | 버전 문자열(`ProjectI-0.37`)이 다르거나 4명이 차면 이유와 함께 거부한다. |
| 끊김 | 참가자는 메인 메뉴로 돌아가 이유를 표시한다. 방장에게는 대원 참가·퇴장 알림이 뜬다. |
| 설정 | 넷코드 씬 관리 **끔**(씬 교체는 Project I 맵 로더가 직접 맞춤), 초당 30틱, 연결 시도 10초 |

## 2. 원정대원 몸체 — `NetPlayerAvatar` (플레이어 프리팹)

- 각자 자기 상태를 초당 20번 보낸다 (주인만 쓰기 가능).
  - 위치·방향: 마차 이동 중에는 마차 기준 좌표
  - 마차 탑승 여부, 쓰러짐, 웅크림, 지금 있는 맵
- 다른 대원 화면에서는 부드럽게 따라간다. 4m 이상 벌어지면 즉시 이동하고, 다른 맵에 있으면 숨긴다.
- 모습: 코트, 머리, 중절모, 주황 목도리, 등짐, 카메라를 보는 이름표 "원정대원 N". 충돌은 없다.
- 내 몸체는 나에게 숨긴다 (1인칭).

## 3. 방장 기준 월드 — `NetWorldState`

| 값 | 참가자 적용 |
| --- | --- |
| 일차 · 원정 단계 · 캠페인 시드 | `DailySnapshotService.ApplyGuestState` — 같은 시드와 일차로 **같은 던전**을 만든다 |
| 게임 시각 | 약 5분 이상 어긋나면 맞춘다 |
| 마차 목적지 · 실패 귀환 | 방장이 출발하면 참가자도 같은 이동 절차로 따라간다. 늦게 들어온 참가자는 방장이 있는 맵으로 이동한다(마차 밖이면 창고로 옮김). |
| 공동 자금 | 표시만 맞춘다 (판매·구매 동기화는 38일차) |

| 요청 | 흐름 |
| --- | --- |
| 참가자가 마차 종 | 방장에게 요청 → 방장이 출발 조건 확인. 불가하면 그 대원에게만 이유, 출발하면 모두에게 종소리·연출 |
| 던전 문 | 누가 열든 방장에게 요청(열쇠 사용 여부 포함) → 모두에게 같은 상태 적용. 문은 "씬 이름 + 계층 경로(이름#순서)"로 찾는다. |

## 4. 바뀐 규칙

- **출발 조건:** 살아 있는 원정대원이 **모두 마차 창고에 타야** 출발한다 ("모든 원정대원이 마차 창고에 타야 합니다 (n명 대기 중)").
- **원정 실패:** 던전에서 **전원이 쓰러졌을 때만** 방장이 실패 귀환을 시작한다. 동료가 살아 있으면 쓰러진 채 기다리고, 참가자는 방장의 판단을 따른다.
- **방장 전용:** 하루 마감, 이전 일차 되돌리기, 모든 저장. 참가자에게는 "하루 마감은 방장만 할 수 있습니다" 안내가 뜬다.
- 메인 메뉴로 이동할 때는 항상 협동 연결을 정리한다.
