37~43일차에 협동 기능(방·아이템·전투·Steam·코드·보안·음성)을 만들었지만, 두 사람이 처음부터 끝까지 함께 해 본 적은 없다. 44일차에는 새 기능 대신 **어긋남을 찾아 알리고 스스로 고치는 장치**, **빌드 두 개 자동 시험**, **사람용 점검표**를 만든다.

```text

F1 Coop 페이지 · 60초마다 "협동 요약" 로그 · 자동 2인 시험 결과 파일
```

## 1. 찾아서 고친 문제 — 던전 문 상태

- `DungeonDoor`는 열고 닫는 순간만 방송해서 **늦게 들어온 대원·재접속한 대원이 열린 문을 닫힌 문으로** 봤다.
- 문이 `INetworkDevice`를 구현하도록 바꿨다(`NetworkState` 0/1, `ApplyNetworkState(int)`) → 전체 상태 전송(`FullStateRpc`)에 자동으로 포함된다.
- 참가자가 장치 요청(`DeviceChangedRpc`)으로 잠긴 문을 여는 우회 경로가 생기지 않게, 문은 장치 경로로 바꿀 수 없게 막았다. 문은 열쇠를 확인하는 `RequestDoorRpc`로만 바뀐다.

## 2. 화면 요약 비교 — `NetConsistency`

| 항목 | 내용 |
| --- | --- |
| 요약 `CoopSnapshot` | 일차 · 자금 · 맵 · 비교 가능 여부 · 바닥 아이템 수·ID 해시(손·주머니·보관·판매 제외) · 장치·문 수·상태 해시 · 체력 대상 수·체력 해시 |
| 보고 | 참가자 몸체가 30초마다 `ConsistencyReportRpc`(몸체 주인만 · `NetGuard` 새 종류 `Report` 0.5/3) |
| 비교 | 방장이 자기 화면으로 다시 계산한다. 이동 중이거나 다른 맵이면 건너뛴다. 사무소에서는 자금도 비교한다 |
| 판정 | 한 번 다르면 대기(전달 중일 수 있음), **두 번 연속** 다르면 `협동 불일치` 경고 |
| 치료 | 아이템 → `NetItemSync.ForceResync`(모든 참가자 목록 다시 받기) · 장치·문·체력 → `NetCombatSync.PushFullStateTo(대원)` |
| 집계 | 비교·일치·불일치·치료 횟수, 마지막 결과 문구 |

- 몸체(플레이어 프리팹)에 RPC를 붙였다 → 네트워크 프리팹 재생성 불필요.

## 3. F1 → `Coop` 페이지 — `NetDebugPage`

- 유지 오브젝트 `===ProjectI Coop Diagnostics===`에 붙어 F1 창에 자동으로 등록된다.
- 표시 항목
  - 역할 · 연결 방식 · 접속 버전 · 방 코드·잠금·Steam 로비
  - 원정대원 줄: 번호·이름·지연·생존/쓰러짐·탑승·말하기·위치(다른 맵이면 표시)
  - 동기화: 내 맵 / 방장 목적지 / 일차, 마지막 아이템 목록 수, 몬스터 따라가기 수, 내 화면 요약·해시, 점검 결과
  - 보안·음성: 거절·자동 내보냄, 음성 보냄·방장 중계
- 협동 중 60초마다 `[Project I] 협동 요약 / …` 한 줄을 남긴다.
- 음성: 방장이 받은 참가자 음성 조각 수 `VoicePacketsRelayed`를 추가했다.

## 4. 자동 2인 시험 — `CoopAutoTest`

- 실행 인자: `-coopAutoHost` / `-coopAutoJoin <주소>` / `-coopAutoResult <파일>`
- 시험 조건: 전용 포트 7787, Steam 사용 안 함, 창이 가려져도 진행, 30fps, 소리 끔, 점검 간격 5초, 전체 제한 200초
- 시험 모드에서는 저장된 해상도를 무시하고 960×540 창으로 띄운다(`GameSettings`).

| 방장 | 참가자 |
| --- | --- |
| 메인 메뉴 도착 | 메인 메뉴 도착 · 4초 대기 |
| 주소 방 열기 → 이어하기(저장 없으면 1일차) | 입장 (실패하면 최대 10번 다시) |
| 게임 월드·방 열림 | 사무소 도착 |
| 참가자 접속 2/4 | 방장 일차와 같음 · 아이템 목록 받음 |
| 참가자 화면 점검 일치 · 불일치 기록 없음 | 원정대원 몸체 2개 · 방장 몸체가 같은 맵에 보임 |
| 참가자 음성 조각 10개 이상 중계 · 거절 0 | 합성 440Hz 음 2초 전송 (50조각) |
| 참가자 나감 처리 | 나가기 → 혼자 하기 상태 |

- 결과는 PASS/FAIL 줄과 요약으로 파일에 저장하고 스스로 끈다. 출발·귀환을 하지 않으므로 저장 파일은 바뀌지 않는다.
