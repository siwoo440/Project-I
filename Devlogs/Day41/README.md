# 41일차 — 방 코드로 입장

## 이번 일차 목표

40일차까지는 Steam 방 목록에서 방을 고르거나 IP 주소를 알아야 참가할 수 있었다. 41일차에는 **짧은 방 코드**만 주고받으면 참가할 수 있게 만든다.

```text
방장: 방 만들기 → 코드 K7Q-2MX 생성 → 로비 데이터에 기록 → 알림·Esc 창에 표시 (복사 가능)
참가자: 서버 창 "코드·주소" 칸에 코드 입력 → [ 입장 ] → 같은 코드 로비 찾기 → 들어가기 → 방장에게 연결
```

## 1. `RoomCode`

| 기능 | 내용 |
| --- | --- |
| 만들기 | 암호 난수로 6자리를 만든다. 글자판은 `0·O·1·I`를 뺀 32자여서 글자별 치우침이 없다. |
| 표시 | `K7Q-2MX` (가운데 하이픈) |
| 정리 | 대문자로 바꾸고 하이픈·공백을 무시한다 (`k7q 2mx` → `K7Q2MX`). |
| 구분 | `.`·`:`가 없는 입력(`localhost` 제외)은 코드로 본다. 형식이 틀리면 주소로 연결하지 않고 이유를 알려 준다. |
| 주소 | `주소` 또는 `주소:포트` 형식. 빈칸이면 같은 컴퓨터(127.0.0.1)다. |
| 내 IP | 켜진 네트워크 장치의 첫 IPv4 주소 (직접 IP 방에서 안내) |

- `RoomVisibility { Public, CodeOnly }`: 방 공개 범위

## 2. Steam 로비

- 로비 데이터에 `code`(방 코드)와 `listed`(공개 방이면 `1`)를 추가로 기록한다.
- 코드 전용 방은 `Invisible` 로비로 만든다. 검색은 되지만 서버 목록과 친구 목록에는 보이지 않는다.
- 서버 목록 요청에 `listed = 1` 조건을 붙였다.
- `FindByCode`: 같은 게임·같은 코드인 로비를 전 세계에서 최대 10개 찾는다.
  - 버전이 같은 로비가 있으면 그 로비를 반환하고, 가득 찼으면 거절한다.
  - 버전만 다른 로비뿐이면 `게임 버전이 다릅니다 (방 … · 내 …)`
  - 결과가 없으면 `코드 … 인 방이 없습니다 (닫혔거나 가득 찬 방)` (가득 차면 방장이 검색에서 숨긴다)

## 3. `NetworkSession`

- `BeginHost(port, visibility)`: 공개 범위를 받아 Steam 로비를 만들 때 코드와 함께 넘긴다.
- `BeginCodeJoin(input)`: 코드 확인 → 로비 찾기 → 들어가기 → 연결 순서로 진행한다. 찾는 동안 Esc로 취소할 수 있다.
- `ShareCode`: 친구에게 알려 줄 값을 돌려준다.
  - Steam 방이면 방 코드
  - 직접 IP 방장이면 `내 IP:포트`
  - 직접 IP 참가자면 들어간 주소
- 방장 알림: `공개 방 코드 K7Q-2MX — Esc 창에서 복사·초대`, 직접 IP 방은 `방을 열었습니다 — 주소 192.168.x.x:7777`
- 로비 찾기·들어가기에 실패하면 먼저 혼자 하기 상태로 바꾼 뒤 알린다 → 메뉴의 버튼이 다시 풀린다 (40일차에는 실패 후에도 버튼이 잠겨 있었다).
- 기다리는 사이 취소했는데 로비 입장이 뒤늦게 성공하면 그 로비에서 바로 나간다.

## 4. 화면

- **서버 창 아래 줄**: `[ 방 만들기 ]  [ 공개 방 [X] / 코드 전용 [ ] ]  코드·주소 [입력칸] : [포트]  [ 입장 ]`
  - Enter로도 입장한다.
  - 포트 칸은 주소에 포트를 적지 않았을 때만 쓴다.
- **Esc 창**
  - 안내 아래에 `방 코드 K7Q-2MX (코드 전용)` 또는 `주소 …`를 표시한다. 로비 생성을 기다리는 동안에는 `방 코드 준비 중...`이다.
  - **코드 복사 / 주소 복사** 버튼으로 클립보드에 복사하고 2초간 `복사됨`을 표시한다.
  - 친구 초대 버튼이 없으면 복사 버튼이 한 줄 위로 올라간다.
